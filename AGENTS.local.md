# snoka-club — local agent rules

Standing user orders. These override convenience; never violate them.

1. Never write code outside the project directory. Scratch scripts, checks,
   and temp files all live inside this repo (e.g. `scripts/`). Never use
   /tmp or any other external path.
2. Never take screenshots, ever. Diagnose visually-described problems via
   DOM markup and computed styles, never images.
